# ПроРабота — рабочая версия MVP

Стек: Python 3.12, aiogram 3, PostgreSQL, Redis, Docker, Google Sheets, Google Calendar + Google Meet. Оплата — тестовая заглушка.

## Сценарий
1. Пользователь /start → анкета → заявка.
2. Заявке автоматически назначается менеджер с минимальным числом заявок.
3. Администратор может переназначить менеджера через админ-панель.
4. Менеджер получает заявку в «👨‍💼 Кабинет менеджера» и может менять статус.
5. Только заявка со статусом `contacted` и назначенным менеджером получает доступ к записи.
6. Клиент выбирает свободный слот календаря менеджера; перед созданием события слот проверяется повторно.
7. Создаётся событие Google Calendar + Google Meet, заявка становится `consultation_booked`.
8. После консультации менеджер ставит `consultation_completed`, затем `waiting_payment`.
9. Клиент нажимает «💳 Оплата» — тестовая заглушка имитирует успешную оплату; заявка становится `onboarding`, роль пользователя `client`.
10. Клиент получает обучение: модули → задания → «Задание выполнено».
11. Напоминания о встрече отправляются за 24 часа и за 1 час.
12. Перенос/отмена встречи запрещены менее чем за 4 часа.

## Менеджер
Администратор:
`/make_manager TELEGRAM_ID`

Календарь менеджера:
`/set_calendar TELEGRAM_ID CALENDAR_ID`

Если у менеджера календарь не задан, используется `GOOGLE_CALENDAR_ID` из `.env`.

## Google Calendar
1. Google Calendar → календарь менеджера → Настройки и общий доступ.
2. Скопировать «Идентификатор календаря».
3. Дать service account доступ «Вносить изменения в мероприятия».
4. Включить Calendar API.
5. Положить JSON сервисного аккаунта в `credentials/google-service-account.json`.

## Запуск
`cp .env.example .env` → заполнить `.env` → `docker compose up --build -d`.

Проверка:
`docker compose logs -f prorobota_bot`

Не передавай секретный JSON сервисного аккаунта в Git или публичный архив.
